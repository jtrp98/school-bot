# เตรียมเครื่องให้ Block Lab ส่งโปรแกรมลงบอร์ด UNO

สำหรับครูหรือผู้ดูแลเครื่องในห้องเรียน ทำครั้งเดียวต่อเครื่อง

Block Lab ต่อบล็อก ดูโค้ด Arduino C++ และตรวจบล็อกได้ทันทีหลังติดตั้ง School Bot ส่วนปุ่ม **ส่งลงบอร์ด**
ต้องมีตัวแปลงโค้ดของ Arduino ในเครื่องก่อน School Bot ไม่ได้ใส่มาให้ จึงต้องติดตั้ง Arduino IDE แยก

## สิ่งที่ต้องมี

| สิ่งที่ต้องมี | หมายเหตุ |
| --- | --- |
| Windows 10 หรือ 11 | เวอร์ชันนี้ส่งลงบอร์ดได้เฉพาะ Windows |
| School Bot | ติดตั้งจาก setup.exe หรือ .msi ของทีม |
| Arduino IDE 2.2 ขึ้นไป | School Bot ใช้ตัวแปลงโค้ดที่อยู่ในนั้น |
| Arduino AVR Boards (`arduino:avr`) | ชุดสำหรับบอร์ด UNO ติดตั้งผ่าน Arduino IDE ต้องต่ออินเทอร์เน็ตครั้งแรก |
| ไดรเวอร์ CH340 | เฉพาะบอร์ดโคลนที่ใช้ชิป CH340 และ Windows ยังไม่รู้จักบอร์ด |

Library ที่บล็อกใช้ (เช่น จอ OLED เซนเซอร์ต่างๆ) มากับ School Bot แล้ว ไม่ต้องติดตั้งเพิ่ม

## ขั้นตอน

1. **ติดตั้ง Arduino IDE 2** จาก <https://www.arduino.cc/en/software> หรือสั่งใน PowerShell:

   ```powershell
   winget install ArduinoSA.IDE.stable
   ```

   ติดตั้งที่ตำแหน่งที่ตัวติดตั้งเลือกให้ ห้ามย้ายโฟลเดอร์ School Bot หาเฉพาะ
   `%LOCALAPPDATA%\Programs` และ `%ProgramFiles%` (โฟลเดอร์ `Arduino IDE` หรือ `arduino-ide`)
   ไม่ค้นจาก PATH
2. **เปิด Arduino IDE หนึ่งครั้ง** แล้วติดตั้ง Arduino AVR Boards ถ้าโปรแกรมถามให้กดติดตั้ง หรือไปที่
   Boards Manager ค้นหา "Arduino AVR Boards" แล้วกด Install รอจนเสร็จแล้วปิด Arduino IDE
3. **เสียบบอร์ด UNO** ถ้าเป็นบอร์ดโคลน CH340 แล้ว Device Manager ไม่ขึ้น `USB-SERIAL CH340 (COMx)`
   ให้ติดตั้งไดรเวอร์ CH340 ของ WCH
4. **ทดลองใน School Bot:** เข้า Block Lab → กด **เปลี่ยน** ที่แถบบน → กด **ใช้ตัวนี้** ที่การ์ดบอร์ด →
   กด **เชื่อมต่อ** → ต่อบล็อกสั้นๆ เช่น Serial พิมพ์ข้อความ → กด **ส่งลงบอร์ด** ครั้งแรกใช้เวลานานกว่าปกติ
   เพราะต้องแปลงโค้ด library ครั้งเดียว

## ข้อควรรู้ในห้องเรียน

- **เสียบเฉพาะบอร์ดที่จะใช้** บอร์ดโคลน CH340 กับแขนกลบางรุ่นใช้ชิปเดียวกัน แอปแยกจากกันไม่ได้
  แอปไม่ยอมส่งลงพอร์ตที่ Arm Lab ใช้ไปแล้วในรอบนี้ (ขึ้นรหัส E-ARM) แต่ควรถอดแขนกลก่อนสอน Block Lab
- **บอร์ดโคลนไม่มีเลขประจำตัว** ถอดสายแล้วเสียบกลับ ต้องกด **ใช้ตัวนี้** และปุ่มเชื่อมต่อใหม่ แอปให้ยืนยันว่าเป็นตัวเดิม
- **ระหว่างส่งลงบอร์ดห้ามถอดสาย** ถ้าจำเป็นต้องหยุด ให้กด **ยกเลิก** แล้ว **หยุดส่ง** หลังหยุดกลางทาง บอร์ดอาจไม่มีโปรแกรมที่ใช้ได้
  ให้กด **ลองอีกครั้ง** การปิดแอประหว่างส่ง แอปจะรอส่งเสร็จก่อน (ไม่เกิน 2 นาที)
- **เปิดอ่านข้อความจากบอร์ด** (แท็บ Output) ทำให้บอร์ดเริ่มโปรแกรมใหม่หนึ่งครั้ง ระหว่างอ่าน Arduino IDE หรือโปรแกรมอื่น
  ใช้พอร์ตนั้นไม่ได้ จนกว่าจะออกจาก Block Lab
- **Arduino IDE ไม่ต้องเปิดค้าง** ถ้าเปิด Serial Monitor ของ Arduino IDE ค้างไว้ School Bot จะส่งลงบอร์ดไม่ได้

## รหัสที่เด็กอ่านให้ครูฟัง

| รหัส | ความหมาย | ครูทำอะไร |
| --- | --- | --- |
| E-TOOL | ไม่พบ Arduino IDE หรือยังไม่ได้ติดตั้ง Arduino AVR Boards | ทำขั้นตอนที่ 1–2 แล้วกดส่งใหม่ |
| E-BUILD | แปลงโค้ดไม่ผ่าน | เปิดรายละเอียดบนการ์ดดูข้อความของเครื่องมือ ส่วนใหญ่มาจากบล็อกที่ยังไม่ครบ |
| E-USB | ส่งลงบอร์ดไม่สำเร็จ หรือสาย USB หลุด | เสียบสายแน่น ปิด Serial Monitor ของโปรแกรมอื่น แล้วกดส่งใหม่ |
| E-TIME | แปลงโค้ดหรือส่งนานเกินเวลาที่กำหนด (ประมาณ 2 นาที) | ลองใหม่ ครั้งแรกนานกว่าปกติเพราะแปลง library ถ้าส่งแล้วยังเป็น ให้ตรวจสาย USB |
| E-BUSY | แอปกำลังทำงานอื่นอยู่ | รอสักครู่แล้วกดใหม่ |
| E-ARM | พอร์ตนี้แขนกลใช้อยู่ | เลือกพอร์ตของ UNO หรือถอดสายแขนกลแล้วเสียบ UNO ใหม่ |
| E-APP | แอปขัดข้อง | ลองใหม่ ถ้ายังเป็น ให้ปิดแล้วเปิด School Bot ใหม่ และแจ้งทีม |
| E-LONG | ข้อความที่พิมพ์ส่งเข้าบอร์ดยาวเกิน | ให้แบ่งเป็นข้อความสั้นลง |
| E-CHK-01 | ตรวจก่อนส่ง: บล็อกมีช่องค่าที่ยังว่าง | กด "ไปดู" แล้วใส่ค่าในช่องนั้น |
| E-CHK-02 | ตรวจก่อนส่ง: บล็อกไม่ได้ต่อกับ "เริ่มต้น" หรือ "วนซ้ำ" | กด "ไปดู" แล้วลากบล็อกไปต่อ หรือลบออก |
| E-CHK-03 | ตรวจก่อนส่ง: อุปกรณ์สองตัวใช้ขาเดียวกัน | เปลี่ยนขาบนบล็อกให้ตรงกับที่ต่อสายจริง |
| E-CHK-04 | ตรวจก่อนส่ง: บัซเซอร์กับรีโมต IR ใช้พร้อมกันไม่ได้ | เลือกใช้อย่างใดอย่างหนึ่ง |
| E-CHK-05 | ตรวจก่อนส่งไม่สำเร็จ (แอปตรวจบล็อกไม่ได้) | ลองใหม่ ถ้ายังเป็น ให้ปิดแล้วเปิด School Bot ใหม่ และแจ้งทีม |
