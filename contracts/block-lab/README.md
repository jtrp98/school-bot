# Block Lab block catalog

`catalog.json` lists the blocks of the Block Lab toolbox for the Arduino UNO, by rail
category (the 16 ids in `app/frontend/src/modes/block-programming/blockly/categories.ts`).
It is the contract between the toolbox and the mixly engine: the engine test
`TestBlockLabCatalogBlocksHaveGenerators` fails when a listed block has no generator.
The frontend builds the toolbox from it (`app/frontend/src/modes/block-programming/blockly/toolbox.ts`),
leaving out `deferred` blocks.

- `type`: an upstream Mixly block type, or a School Bot `sb_*` type defined in
  `engines/mixly/src/` (fields and inputs: `engines/mixly/docs/API.md`).
- `group`: sub-heading inside the Sensor category.
- `device`: the module's English name on the team's block sheet.
- `status: "deferred"`: generated by the engine but kept out of the v1 toolbox.
- `userCreated`: the category starts empty and shows the blocks children create
  (functions, lists), as in Scratch.

The source is the team's block sheet "[School Bot] Fuction - Block Mixly" and its
new-block specification. Update this file when the sheet changes.
