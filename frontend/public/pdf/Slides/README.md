# สไลด์คาบเรียนที่ 1–4

วางไฟล์ PDF ในโฟลเดอร์นี้ โดยใช้ชื่อไฟล์ตรงตามนี้:

- `basic-1-periods-1-4.pdf` — สไลด์ “AI ใกล้ตัว” สำหรับ Basic 1 คาบเรียนที่ 1–4 (ใส่แล้ว)
- `basic-2-periods-1-4.pdf` — สไลด์ Basic 2 คาบเรียนที่ 1–4 (รอไฟล์)

เมื่อเพิ่มไฟล์แล้ว ให้เริ่ม `npm run dev` ใหม่ในเครื่อง หรือรัน `npm run build` ใหม่ก่อนเผยแพร่เว็บ เพื่อให้ปุ่ม “ดูสไลด์” เปิดใช้งาน
