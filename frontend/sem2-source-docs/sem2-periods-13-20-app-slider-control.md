**ส่วนที่ 3: ฟีเจอร์ในแอป**

แอปแบ่งเป็น 3 แท็บหลัก:

**แท็บที่ 1: Robot Control**

หน้าตา:

- มี Slider (แถบเลื่อน) สำหรับแต่ละ Servo

- มีปุ่ม Action Group ด้านล่าง

**การใช้งาน:**

**1. ควบคุม Servo แยกตัว:**

- Slider 1: Base (0-180°)

- Slider 2: Shoulder (0-180°)

- Slider 3: Elbow (0-180°)

- Slider 4: Wrist Rotation (0-180°)

- Slider 5: Wrist Pitch (0-180°)

- Slider 6: Gripper (เปิด-ปิด)

**วิธีใช้:**

- แตะที่ Slider แล้วเลื่อนซ้าย-ขวา

- ดูค่ามุมที่ต้องการ (แสดงเป็นตัวเลข)

- แขนกลจะขยับตามทันที

**2. เรียก Action Group:**

- ปุ่ม Action 1, 2, 3, 4...

- กดปุ่มใด Action นั้นจะทำงาน

- Action เหล่านี้มาจาก PC หรือสร้างในแอป

**ข้อดี:**

- ควบคุมแม่นยำ เห็นค่ามุมชัดเจน

- ปรับละเอียดได้ 1 องศา

- เรียก Action ได้สะดวก

**3. เรียก Reset:**

- เริ่มการทำงานของแขนกลใหม่

**4. การดึง Action จาก PC มาใช้งาน**

- สามารถเข้าไปที่ฟังก์ชั่น Add Action Group 

- สามารถตั้งชื่อ Action ได้

- และต้องป้อนหมายเลขของ Action ให้ตรงกับ หมายเลขที่เราได้บันทึกไว้ใน Pc

**แท็บที่ 2: Create Action **

**คืออะไร?**

- สร้าง Action ใหม่ด้วยการบันทึกการเคลื่อนไหว

**วิธีสร้าง Action:**

**ขั้นที่ 1:** เตรียม Action

- ตั้งชื่อ Action เช่น "หยิบบล็อก"

- กำหนดจำนวน Step (ขั้นตอน)

**ขั้นที่ 2: **เปิดโหมด Mode Off

- กดปุ่ม "Mode Off" หรือ "Teach Mode"

- Servo ทุกตัวจะหลวม สามารถขยับด้วยมือได้

- ข้อควรระวัง: แขนกลอาจตกลงมา ให้พยุงไว้!

**ขั้นที่ 3:** บันทึก Action

- ขยับแขนกลด้วยมือไปท่าที่ 1

- กดปุ่ม "Add Action" → บันทึกเป็น Step 1

- ขยับแขนกลไปท่าที่ 2

- กดปุ่ม "Add Action" อีกครั้ง → บันทึกเป็น Step 2

- ทำซ้ำจนครบทุก Step

**ขั้นที่ 4:** ตั้งค่าเวลา

- กำหนดเวลาแต่ละ Step (เช่น 1000 ms = 1 วินาที)

- ค่ามากขึ้น = เคลื่อนไหวช้า นิ่มนวล

- ค่าน้อยลง = เคลื่อนไหวเร็ว กระตุก

**ขั้นที่ 5: **ทดสอบ Action

- กดปุ่ม "Play" หรือ "▶"

- ดู Action ทำงานถูกต้องหรือไม่

- ถ้าไม่ถูกใจ → แก้ไข Step ที่ผิด

**ขั้นที่ 6:** บันทึก Action

- กดปุ่ม "Save Action"

- Action จะถูกเก็บไว้ในแอป
