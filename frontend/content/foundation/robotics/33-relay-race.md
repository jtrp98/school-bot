**คาบที่ 25 — Relay Race**

**ผลัด 3 ระบบ: PC → Joystick → App (50 นาที | 30 คะแนน)**

**จุดประสงค์**

- บูรณาการทั้ง 3 ระบบในภารกิจเดียวกันอย่างต่อเนื่อง

- สื่อสารและประสานงานภายในทีมเพื่อ "ส่งต่อ" ภารกิจระหว่างระบบ

- วิเคราะห์ว่าระบบใดเหมาะกับขั้นตอนไหนของภารกิจ

**กติกา Relay Race**

**ภารกิจทั้งหมด:** นำบล็อก 3 สี (แดง/น้ำเงิน/เขียว) ใส่ถาดที่ถูกต้องตามสี

**ขั้นที่ 1 (PC Operator):** สร้าง Action Group "เตรียมพร้อม" → ยกแขนไปตำแหน่งเริ่มต้น → Offline

**ขั้นที่ 2 (Joystick Pilot):** รับบล็อกแดง Real-time → วางถาดแดง

**ขั้นที่ 3 (App Commander):** รัน Action Group → หยิบบล็อกน้ำเงิน → วางถาดน้ำเงิน

จับเวลาตั้งแต่ PC กด Offline Run ถึงบล็อกสุดท้ายวางสำเร็จ

🏆 ทีมเวลารวมน้อยที่สุด = แชมป์คาบนี้
