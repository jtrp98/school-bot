**สรุปสาระสำคัญ**

1. Action Group = "โปรแกรมท่าทาง" — บันทึกครั้งเดียว ใช้ได้ทุกเมื่อด้วยปุ่มเดียว

2. Motor Off = เปิดโหมดสอนมือ — ต้องพยุงแขนไว้เสมอ

3. Time ควบคุมความนุ่มนวล — มากขึ้น = ช้าลง นิ่มนวล, น้อยลง = เร็วขึ้น กระตุก

4. Loop เหมาะกับงานซ้ำๆ — ต้องกด Stop เองเสมอ

5. เครื่องมือต่างกัน เหมาะกับงานต่างกัน — ไม่มีวิธีไหนดีที่สุดสำหรับทุกงาน

- การเชื่อมต่อระหว่าง Robo X กับ Application ในสมาร์ทโฟนหรือแท็บเล็ต โดยทั่วไปใช้เทคโนโลยีไร้สายชนิดใด?

ก. คลื่นวิทยุ AM/FM 				ข. สายเคเบิลใยแก้วนำแสง

ค. WiFi หรือ Bluetooth 			ง. สัญญาณดาวเทียม

- ข้อใดคือข้อดีที่เด่นชัดที่สุดของการใช้ "Slider" (แถบเลื่อน) ในแอปพลิเคชัน เมื่อเทียบกับปุ่มกดบน Joystick?

ก. ทำให้หุ่นยนต์มีพละกำลังในการยกของมากขึ้น

ข. สามารถควบคุมความเร็วและความต่อเนื่องของการเคลื่อนที่ได้ละเอียดกว่า

ค. ประหยัดแบตเตอรี่ของหุ่นยนต์ได้มากกว่า

ง. ทำให้หุ่นยนต์เคลื่อนที่ไปได้ไกลขึ้นกว่าเดิม

- หากนักเรียนต้องการให้หุ่นยนต์ "หยุดรอ" เป็นเวลา 2 วินาทีก่อนจะเริ่มขั้นตอนต่อไป นักเรียนควรปรับค่าใดใน Action Editor?

ก. ปรับค่า Time (ms) ในขั้นตอนนั้นให้เป็น 2000

ข. กดปุ่ม Emergency Stop แล้วรอ 2 วินาทีค่อยกดใหม่

ค. ปรับค่า Servo หมายเลข 1 ให้เป็น 0 องศา

ง. ปิดหน้าจอแอปพลิเคชันแล้วนับ 1 ถึง 2 ในใจ

- หากต้องการ "แก้ไข" ท่าทางใน Action Group ที่บันทึกไว้ในแอปพลิเคชัน โดยไม่ต้องการบันทึกใหม่ทั้งหมด นักเรียนควรทำอย่างไร?

ก. ใช้เมนู Edit เพื่อปรับเปลี่ยนเฉพาะองศาหรือเวลาในขั้นตอนที่ผิด

ข. ลบ Action Group นั้นทิ้งแล้วเริ่มบันทึกใหม่ตั้งแต่ต้น

ค. เขย่าแท็บเล็ตแรงๆ เพื่อให้หุ่นยนต์สุ่มท่าทางใหม่

ง. ปิดแอปพลิเคชันแล้วเปิดใหม่เพื่อให้ระบบแก้ไขเอง

- การตั้งค่า "Time" (ms) ใน Action Editor ส่งผลอย่างไรต่อการทำงานของหุ่นยนต์?

ก. ยิ่งค่าน้อย หุ่นยนต์จะเคลื่อนที่นุ่มนวลขึ้น

ข. ยิ่งค่าน้อย หุ่นยนต์จะยิ่งเคลื่อนที่เร็วและกระชาก

ค. ค่านี้ใช้กำหนดว่าจะให้หุ่นยนต์ทำงานกี่รอบ

ง. ค่านี้ไม่มีผลใดๆ ต่อการเคลื่อนที่ของหุ่นยนต์

- เมนู "Insert" (แทรก) ในหน้าจอ Action Editor มีประโยชน์อย่างไร?

ก. ใช้สำหรับลบท่าทางที่ไม่ต้องการทิ้ง

ข. ใช้เปลี่ยนสีของหุ่นยนต์ในหน้าจอแอปฯ

ค. ใช้เพิ่มท่าทางใหม่ลงไปตรงกลางระหว่างท่าที่บันทึกไว้แล้ว

ง. ใช้เพื่อหยุดการทำงานของหุ่นยนต์ชั่วคราว

- ทำไมการควบคุมผ่าน Application จึงจัดอยู่ในกลุ่มระบบ "Human-on-the-Loop" เมื่อใช้โหมดอัตโนมัติ?

ก. เพราะมนุษย์ต้องถือแท็บเล็ตแล้วเดินวนรอบหุ่นยนต์

ข. เพราะมนุษย์ทำหน้าที่เฝ้าดูหน้าจอและกดหยุดได้ทันทีเมื่อเกิดปัญหา

ค. เพราะหุ่นยนต์ต้องการความอบอุ่นจากมือมนุษย์

ง. เพราะแอปพลิเคชันมีรูปร่างเป็นวงกลม (Loop)

- หากนักเรียนต้องการทำภารกิจคัดแยกวัตถุจากระยะไกล 5 เมตร ข้อดีของการใช้แอปฯ คืออะไร?

ก. หุ่นยนต์จะฉลาดขึ้นเองเมื่อเราอยู่ไกลออกไป

ข. น้ำหนักของแขนหุ่นยนต์จะเบาลง

ค. ทำให้สัญญาณอินเทอร์เน็ตที่บ้านเร็วขึ้น

ง. ไม่ต้องกังวลเรื่องสายเชื่อมต่อที่ยาวไม่พอ

- ในกิจกรรม "The Glass Maze" (ทางวิบาก) สิ่งสำคัญที่สุดที่นักเรียนได้เรียนรู้คืออะไร?

ก. การควบคุมความเร็วและความนุ่มนวลเพื่อหลบหลีกสิ่งกีดขวาง

ข. การทำอย่างไรให้ขวดน้ำล้มให้มากที่สุด

ค. การตะโกนเชียร์เพื่อนให้เสียงดังที่สุด

ง. การเล่นเกมในแท็บเล็ตระหว่างรอเพื่อน

- การเรียนรู้เรื่อง Action Editor เป็นพื้นฐานสำคัญก่อนจะไปเรียนเรื่องใดในหน่วยถัดไป?

ก. การวาดรูปศิลปะด้วยพู่กัน

ข. การเขียนโปรแกรม (Coding) สั่งงานหุ่นยนต์

ค. การซ่อมแซมแผงโซลาร์เซลล์

ง. การประกอบอาหารไทย
