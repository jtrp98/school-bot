**คาบที่ 26 กิจกรรม : 8 Obstacle Avoidance – หลบสิ่งกีดขวาง ” (50 นาที)**

**ภารกิจ : **“พา gripper จากจุดเริ่ม → ไปแตะเป้าหมาย โดย ‘ห้ามชน’ สิ่งกีดขวาง”

**อุปกรณ์:**

- กล่อง / แก้ว / หนังสือ วางเป็นกำแพงเล็กๆ

**เงื่อนไข:**

- อย่างน้อย 5–8 Actions

- ต้องมี “ท่าหลบ” (ยกขึ้น/อ้อม/หมุน)

**Step 1:** วิเคราะห์เส้นทาง
	(ให้เด็กวาด/คิดก่อน/จะ “ยกข้าม” หรือ “อ้อมซ้าย/ขวา”)

**Step 2:** สร้าง Action ทีละช่วง

ตัวอย่างลำดับ:

- ยกแขนขึ้น (เคลียร์สิ่งกีดขวาง)

- เคลื่อนไปด้านหน้า

- ลดระดับลงหลังพ้น

- ปรับตำแหน่งให้ตรงเป้า

- แตะเป้าหมาย

แต่ละขั้น:

- Manual → จัดท่า

- ตั้ง Duration

- Add action

**Step 3:** Run และสังเกต

**Step 4:** Debug แบบมีเหตุผล

ถามให้เด็กตอบก่อนแก้:

- ชนเพราะ “ลำดับผิด” หรือ “มุมผิด”

- ต้องแก้ Action ไหน

แล้วค่อย:

- แก้ และ Update action (ไม่ใช่ลบทั้งชุด)
