**คาบที่ 28 — System Design**

**ออกแบบสายการผลิตจริง (50 นาที | 35 คะแนน)**

**จุดประสงค์**

- ออกแบบระบบที่ใช้ทั้ง 3 ระบบควบคุมในขั้นตอนที่เหมาะสมที่สุด

- สร้าง "สายการผลิต" จำลองที่มีประสิทธิภาพ โดยใช้จุดแข็งของแต่ละระบบ

- นำเสนอและปกป้องการออกแบบด้วยเหตุผลทางวิศวกรรม

**โจทย์ System Design**

| **ภารกิจ:** ออกแบบ "โรงงานขนมปัง" จำลอง  นำบล็อก 5 ชิ้นจากจุดวัตถุดิบ → ผ่านสายการผลิต → ไปถาดสินค้าสำเร็จรูป 📌 **เงื่อนไขบังคับ:** ต้องใช้ PC Software อย่างน้อย 1 ขั้นตอน (เช่น เตรียมตำแหน่ง Home) ต้องใช้ Joystick อย่างน้อย 1 ขั้นตอน (เช่น Real-time sorting) ต้องใช้ App Action Group อย่างน้อย 1 ขั้นตอน (เช่น ขั้นตอนซ้ำๆ) **ต้องส่ง:** แผนผัง System Design + สาธิตจริง |

**ตารางกิจกรรม**

| **เวลา** | **กิจกรรม/เนื้อหา** | **ครูทำ** | **นักเรียนทำ** |
| --- | --- | --- | --- |
| 0–5 นาที | Hook: ดูวิดีโอสายการผลิตจริง 2 นาที — "หุ่นยนต์ทำงานอะไร?" | เปิดวิดีโอ | ดู + ตั้งคำถาม |
| 5–18 นาที | Design Phase: วาดแผนผัง System Design ใบงาน Part 1 | เดินดู ตั้งคำถาม Socratic | วาด + เขียน Justification |
| 18–40 นาที | Build & Test: สร้างระบบจริงตามแผน ทดสอบ + ปรับแก้ | บันทึก Score ทดสอบ | Build → Test → Iterate |
| 40–50 นาที | System Showcase: นำเสนอแผน + สาธิตสด 3 นาที/ทีม | ให้คะแนน | Present + Defend Design |
