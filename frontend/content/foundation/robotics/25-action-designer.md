**The Action Designer**

**Talk: ชวนคุย**

"นักเรียนครับ ที่ผ่านมาเวลาเราบันทึก Action ผ่าน PC แล้วควบคุมการใช้งานในจอยสติ๊ก ถ้าเราทำผิดนิดเดียว เราต้องลบใหม่หมดเลยใช่ไหม? แต่ในแอปพลิเคชันนี้ เราสามารถ 'จิ้ม' เข้าไปแก้ไขแค่จุดที่ผิดได้เหมือนเราแก้ไขข้อความในมือถือเลย!"

**Create Actions: สร้างท่าทางแรกของเรา**

| **เป้าหมายคาบนี้** เข้าใจโครงสร้างของ Action Group (Index / Time / Servo ID) สร้าง Action Group อย่างน้อย 1 ชุดด้วยโหมด Motor Off + Add Action Run Online และบันทึก Action Group ใน My Actions ได้ | **อุปกรณ์** Robo X (เปิดและรอ Bluetooth พร้อม) แท็บเล็ต/มือถือ — Wonderbot ใบงาน Action Designer (ใบงาน 17) บล็อก EVA 1 ชิ้น |

**ขั้นตอนการสร้าง Action Group (ทีละขั้น)**

- เปิด Wonderbot → เชื่อมต่อ Robo X → เข้าหน้า Create Actions

- กด Motor Off → รับ OK → ข้อต่อจะหลวม (จับพยุงแขนไว้!)

- ขยับแขนกลด้วยมือไปท่าที่ 1 → กด Add Action → บันทึก Step 1

- ขยับไปท่าที่ 2 → กด Add Action → บันทึก Step 2 (ทำซ้ำจนครบ)

- กด Time (1000ms) → ปรับความเร็วแต่ละ Step

- กด Run Online เพื่อทดสอบ → ดูผล → ปรับแก้ถ้าไม่ถูกใจ

- กด Save Action Group → ตั้งชื่อ → บันทึกลง My Actions

**ข้อควรระวัง:** หลังกด Motor Off แขนกลจะหลวมและอาจตกลง ให้พยุงแขนไว้ด้วยมืออีกข้าง และวางแขนในพื้นที่โล่งก่อนเสมอ
