**วิธีควบคุม Servo: มี 2 แบบ**

**แบบที่ 1: ใช้ Slider**

**แบบที่ 2: พิมพ์ค่าตัวเลข**

- กด Enter

- Servo จะขยับไปตามค่านั้นพอดี

- **ความหมายของ Action และการสร้าง Action Group**

**Action** มีความหมายว่า : คำสั่งการเคลื่อนไหว “เดี่ยว” ของหุ่นยนต์ในช่วงเวลาหนึ่ง

พูดง่ายๆก็ คือ “ท่าหนึ่งท่า” หรือ “คำสั่งหนึ่งคำสั่ง” ที่เราสั่งให้หุ่นยนต์ทำ

**ตัวอย่าง:**

- หมุนเซอร์โวข้อศอกไปที่ 90°

- เปิด/ปิด gripper (คีมหนีบ)

- ยกแขนขึ้น

- หมุนฐานไปทางซ้าย

ในเชิงเทคนิค Action มักจะประกอบด้วย:

- มุมของ servo แต่ละตัว

- เวลา (duration) ที่ใช้เคลื่อนที่

**Action Group (กลุ่มแอคชัน)**

มีความหมายว่า : ชุดของหลายๆ Action ที่ถูกเรียงลำดับไว้ เพื่อให้หุ่นยนต์ทำงานเป็น “พฤติกรรมหนึ่งอย่าง”

พูดง่ายๆก็คือ “หลายท่า(Action)มารวมกันจนกลายเป็น 1 งาน”

**ตัวอย่าง:**
	Action Group: “หยิบของ”

- แขนยื่นออกไป

- กาง gripper

- ลดแขนลง

- หนีบของ

- ยกขึ้น

- ดึงกลับ

หรือจะเปรียบเทียบว่า Action Group: “เต้น”

หรือก็คือการรวมหลาย Action เช่น หมุน, ยก, ส่าย ต่อเนื่องกัน

**วิเคราะห์ Slider แต่ละ ID** 

**Servo ID:1 Gripper**

- เป็น Servo ID ที่ควบคุมการเคลื่อนไหวของ Gripper (มือจับ) 

- มีค่า ตั้งแต่ 0-1000

- **R **หมายถึง เปิดออก/กางออก (Release) เมื่อเราเลื่อน Slider ไปทางตัว **R** Gripper จะกางออก

- **C **หมายถึง ปิดเข้า/หุบเข้า (Close) เมื่อเราเลื่อน Slider ไปทางตัว **C** Gripper จะหุบเข้า

**หมายเหตุ** 
ค่า **R **ที่แนะนำไม่ควรต่ำว่า 100 สำหรับการกางออก

ค่า **C **ที่แนะนำ ไม่ควรเกิน 650 สำหรับการหุบเข้า (หากมากกว่านั้นจะเป็นการฝืน Servo)

ค่าที่เหมาะสำหรับการหยิบ บล็อกสี (EVA Block) อยู่ที่ 500 ระยะการหุบจะไม่ชิดจนเกินไป

Slider ด้านล่าง ค่าเบี่ยงเบน ของ Servo (Servo Deviation ) มีค่าตั้งแต่ -100 - 100 Deviation ไม่ใช่การสั่งให้ขยับ แต่เป็น “การปรับความแม่น” ของตำแหน่ง

ค่าที่ระบบใช้จริง = ค่าหลัก (Position) ± Deviation 
	เช่น ค่าหลัก = 500 (ตำแหน่งกลาง)

        Deviation = -43

        ตำแหน่งจริง = 500-43 = 457

- **แบบ Forward Chain**

การเคลื่อนที่ = ไล่จากฐาน → ปลาย

ID6 → ID5 → ID4 → ID3 → ID2 → ID1

ถ้าฐานขยับ → ตำแหน่งทุกอย่างเปลี่ยนหมด

- **การควบคุมตำแหน่ง = ต้องควบคุมหลาย Servo พร้อมกัน**

ID3 → ปรับมุมให้ตรง

ID2 → หมุนให้ gripper align

ID1 → หนีบ

**สรุปสั้นๆ**

Robo X = ระบบข้อต่อ 6 แกน ทุก servo ทำงาน “สัมพันธ์กัน” เพื่อกำหนด **“ตำแหน่ง + ทิศทาง + การจับ”**

Step2 : ID5 = ยกแขน

Step3 : ID4 = งอแขน

Step4 : ID3 = เอียงมือ 

Step5 : ID2 = หมุนข้อมือ

Step6 : ID1 = หยิบของ (Gripper)

**ตัวอย่างขั้นตอน**

- เปิดโปรแกรมบนพีซีและเชื่อมต่อพอร์ตอนุกรม คลิก “ ผสานรวมไฟล์ ”หรือ “Integrate file” และเปิด Action Group No.0

- ณ ขณะนี้ รายการการดำเนินการจะแสดงข้อมูลของ Action Group No.0

- คลิก“ผสานไฟล์” หรือ “Integrate file” อีกครั้ง และเลือกAction Group No.2 สำหรับการผสาน

- รายการการดำเนินการจะแสดงข้อมูลของ Action Group No.0 และ Action Group No.2

- คลิก “” เพื่อดำเนินการตามคำสั่งที่ผสานรวมใหม่ทางออนไลน์

- คลิก“บันทึกไฟล์”เพื่อบันทึก Action Group แบบใหม่สำหรับการแก้ไขในอนาคต
