**คาบที่ 2: Plan & Design**

**เป้าหมาย**

วางแผนโครงงาน ออกแบบภารกิจ เลือกวิธีควบคุม และออกแบบขั้นตอนการทำงานของแขนกล

**เวลาโดยประมาณ**

- ทบทวนโจทย์ (10 นาที)

- ศึกษาวิธีควบคุม (15 นาที)

- ออกแบบภารกิจ (25 นาที)

- ตรวจแผนกับครู (10 นาที)

**กิจกรรมการเรียนรู้**

- สำรวจวิธีควบคุม

ครูอธิบายภาพรวมของการควบคุม Robo X ผ่าน 3 ทาง
**PC software:** ใช้ตรวจสอบการเชื่อมต่อ ควบคุม servo ดู slider แต่ละ ID และสร้าง Action Group
**Joystick:** ใช้ Button Mapping, Action Group Mode, Single Servo Mode
**Application:** ใช้ Robot Control, Create Action, My Action, App Slider Control และเชื่อมต่อแบบไร้สาย

- ออกแบบวิธีทำงาน

ให้แต่ละกลุ่มออกแบบ จุดเริ่มต้นของวัตถุ จุดปลายทาง จำนวนรอบการทำงาน วิธีควบคุมหลัก วิธีสำรองถ้าการควบคุมหลักไม่สำเร็จ

- วาด Flow การทำงาน

นักเรียนทำแผนภาพง่าย ๆ เช่น เริ่มต้น → จับวัตถุ → ยกขึ้น → หมุน → วาง → กลับตำแหน่งเดิม

- ออกแบบเกณฑ์ความสำเร็จ

ให้เด็กตกลงร่วมกันว่า "ภารกิจสำเร็จ" แปลว่าอะไร เช่น หยิบของได้ 3 ครั้งติด วางในพื้นที่เป้าหมายได้ ใช้เวลาน้อยกว่า 1 นาที วัตถุไม่ตก
