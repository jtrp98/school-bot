**คาบที่ 24 — App Maestro**

**Wonderbot Action Design Competition (50 นาที | 25 คะแนน)**

**จุดประสงค์**

- สร้าง Action Group ใน Wonderbot ที่มีความสร้างสรรค์และแม่นยำ

- นำ Action Group ที่สร้างมา "ท้าทาย" ทีมอื่นด้วยโจทย์ที่กำหนดเอง

- เปรียบเทียบประสิทธิภาพ Action Group ระหว่าง PC และ App

**กติกา App Maestro — Design + Challenge**

**Phase 1 (20 นาที):** แต่ละทีมสร้าง "Signature Action" ของตัวเอง ≥ 5 Steps ใน Wonderbot

**Phase 2 (15 นาที):** แต่ละทีมออกแบบ "โจทย์ท้าทาย" 1 ข้อ สำหรับทีมอื่น (เช่น "วางบล็อกในถ้วย")

**Phase 3 (10 นาที):** สลับโจทย์ แต่ละทีมพยายามแก้โจทย์ของทีมอื่นด้วย App ของตัวเอง

⭐ ทีมที่สร้างโจทย์ยากที่สุด (แต่ตัวเองทำได้) รับ Bonus 3 คะแนน

**ตารางกิจกรรม**

| **เวลา** | **กิจกรรม/เนื้อหา** | **ครูทำ** | **นักเรียนทำ** |
| --- | --- | --- | --- |
| 0–5 นาที | Warm-up: Bluetooth Pairing Sprint — ทีมใด Connect ได้ก่อน | จับเวลา | แข่ง Pair Bluetooth |
| 5–25 นาที | Phase 1 — Design: สร้าง Signature Action ≥ 5 Steps | เดินดู ให้คำแนะนำ | สร้าง AG + Save My Actions |
| 25–33 นาที | Phase 2 — Challenge Design: เขียนโจทย์ท้าทายทีมอื่น | ตรวจโจทย์ว่าทำได้จริง | เขียนโจทย์ + ทดสอบตัวเอง |
| 33–43 นาที | Phase 3 — Cross Challenge: สลับโจทย์กัน | จับเวลาแต่ละทีม | แก้โจทย์ทีมอื่น |
| 43–50 นาที | Showcase: แต่ละทีม Run Signature Action สาธิต + ประกาศคะแนน | บันทึก Score | สาธิต 1 นาที/ทีม |

**ตารางคะแนน App Maestro**

| **เกณฑ์** | **คะแนน** |
| --- | --- |
| Signature Action ≥ 5 Steps บันทึกใน My Actions | 5 |
| Signature Action Run สำเร็จ 2/2 รอบ | 8 |
| แก้โจทย์ทีมอื่นสำเร็จ | 7 |
| ความสร้างสรรค์ของ Signature Action (Peer Vote) | 5 |
| Bonus: สร้างโจทย์ยากที่สุดและตัวเองทำได้ | 3 (Bonus) |
