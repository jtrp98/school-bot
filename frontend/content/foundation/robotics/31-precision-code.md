**คาบที่ 23 — Precision Code**

**PC Software Challenge — โปรแกรมให้แม่นยำที่สุด (50 นาที | 25 คะแนน)**

**จุดประสงค์**

- สร้าง Action Group ผ่าน PC Software ที่ทำภารกิจ Pick & Place สำเร็จ

- Download Action Group ลงบอร์ด Robo X และรัน Offline Mode

- วิเคราะห์ค่า Duration เพื่อหาจุดสมดุลระหว่างความเร็วและความแม่นยำ

**โจทย์: สร้าง Action Group ใน PC Software เพื่อ "หยิบบล็อก A → วางถาด B → กลับ Home"**

**เงื่อนไขพิเศษ:** ต้อง Combine Action Group อย่างน้อย 2 ไฟล์เข้าด้วยกัน

**บังคับ:** Download ลง Board และรัน Offline (ถอดสาย USB ก่อนกด Run)

**Bonus 5 คะแนน:** รันซ้ำ 2 รอบโดย Offline ได้สำเร็จ 2/2 รอบ

**ตารางกิจกรรม**

| **เวลา** | **กิจกรรม/เนื้อหา** | **ครูทำ** | **นักเรียนทำ** |
| --- | --- | --- | --- |
| 0–5 นาที | Hook: "ทีมใดสร้าง AG บน PC ใน 5 นาทีได้บ้าง?" — Speed Coding Warm-up | จับเวลา | แข่งสร้าง AG ง่าย |
| 5–20 นาที | Build Phase: สร้าง Action Group Pick + Place + Home แยกกัน 3 ไฟล์ | เดินดูทุกกลุ่ม | สร้าง AG + บันทึกไฟล์ |
| 20–28 นาที | Combine Phase: รวม 3 ไฟล์เป็น AG เดียว + ทดสอบ Run Online | ช่วยกลุ่มที่ติดขัด | Integrate File + Run Online |
| 28–38 นาที | Offline Phase: Download AG → ถอดสาย → กด Run บน Board | จับเวลา บันทึกผล | Download + Test Offline |
| 38–45 นาที | Bonus Round: รัน Offline รอบที่ 2 | บันทึก Bonus | รัน Offline รอบ 2 |
| 45–50 นาที | ประกาศคะแนน + Debrief | อัพเดท Scoreboard | จด Score + ยุทธศาสตร์ต่อ |
