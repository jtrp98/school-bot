**คาบที่ 26 — Debug Battle**

**แข่งแก้บัก Action Group (50 นาที | 20 คะแนน)**

**จุดประสงค์**

- วิเคราะห์และแก้ไข Action Group ที่มี "บัก" ที่ซ่อนอยู่ได้

- ใช้ทั้ง PC Software และ Wonderbot ในการตรวจสอบข้อผิดพลาด

- พัฒนาทักษะการคิดแบบ Systematic Debugging

**กติกา Debug Battle**

ครูเตรียม Action Group ที่มีบัก 3 ชนิด ซ่อนอยู่ในไฟล์ให้แต่ละทีม

**Bug Type A** — Wrong Value: ค่า Servo ผิด ทำให้แขนไปผิดตำแหน่ง

**Bug Type B** — Wrong Sequence: ลำดับ Step ผิด แขนชนกับสิ่งกีดขวาง

**Bug Type C** — Wrong Timing: ค่า Time น้อยเกินไป แขนกระตุกหรือล้มบล็อก

🏆 ทีมที่พบและแก้ Bug ครบ 3 ชนิดเร็วที่สุด = แชมป์

⚠️ ห้ามเดาสุ่ม — ต้องอธิบายว่า Bug อยู่ที่ Step ใด ค่าอะไร และทำไม

**ตารางกิจกรรม**

| **เวลา** | **กิจกรรม/เนื้อหา** | **ครูทำ** | **นักเรียนทำ** |
| --- | --- | --- | --- |
| 0–8 นาที | สอนตรง: วิธีอ่าน AG แบบ Systematic — ตรวจทีละ Step | สาธิตการอ่าน AG | จดวิธีตรวจบน Post-it |
| 8–15 นาที | แจกไฟล์ AG ที่มีบัก (ทั้ง PC .rob และ App) | แจกไฟล์ | โหลดไฟล์ลงเครื่อง |
| 15–35 นาที | Debug Phase: แต่ละทีมแก้บัก 3 ชนิดแข่งกัน | จับเวลาทีมแรกที่ทำสำเร็จ | วิเคราะห์ + แก้ Bug |
| 35–43 นาที | Verification: Run AG ที่แก้แล้ว — บล็อกต้องวางสำเร็จ | ตรวจสอบผล | Run ทดสอบ |
| 43–50 นาที | Bug Reveal + ประกาศคะแนน: ครูเฉลย Bug ทั้ง 3 ชนิด | เฉลย อธิบาย | ฟัง + จด |
