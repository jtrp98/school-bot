**คาบที่ 3: Build & Test (สร้างและทดสอบ)**

**เวลา:** 60 นาที
 **วัตถุประสงค์:** นักเรียนสร้าง Action และทดสอบจนโครงงานทำงานได้

**โครงสร้างเวลา**

**ส่วนที่ 1: สร้าง Action (30 นาที)**

** ข้อกำหนดสำคัญ:**

- ใช้เฉพาะ PS2/App/PC ควบคุม

- ไม่มีเซ็นเซอร์ = วางของตำแหน่งแน่นอน + ใช้ Action ที่บันทึกไว้

- ผู้ควบคุม(คน)เป็นผู้ตัดสินใจว่าจะเรียก Action ไหน

**การจัดการเวลา:**

- ใช้ Timeboxing = กำหนดเวลาชัดเจนสำหรับแต่ละ Action

- ถ้ามี 6 Action → แต่ละ Action มีเวลา 5 นาที

- ตั้งนาฬิกาปลุก เมื่อหมดเวลาต้องไปทำ Action ถัดไป

**วิธีทำงาน:**

**1. จัดสนาม**

- วิศวกรจัดวางอุปกรณ์ตามแผนผัง

- สำคัญมาก: ใช้เทปกาวหรือดินสอวงกลมทำเครื่องหมายตำแหน่งที่แน่นอน

- วงกลม A = ตำแหน่งช้อน (ต้องวางตรงนี้เสมอ)

- วงกลม B = ตำแหน่งส้อม

- วงกลม C = ตำแหน่งจาน

- เหตุผล: เพราะไม่มีเซ็นเซอร์บอกว่าของอยู่ไหน ต้องวางตำแหน่งเดิม Action จึงจะใช้ได้

**2. เลือกวิธีสร้าง Action**

**วิธีที่ 1:** ใช้ PC Software (แนะนำ - แม่นยำสุด)

- เชื่อมต่อ Robo X กับ PC

- โปรแกรมเมอร์สร้าง Action ทีละ Step

- บันทึกค่ามุม Servo แต่ละตัวอย่างละเอียด

- Upload ไป Robo X

**วิธีที่ 2:** ใช้ App (สะดวก - ทำได้เร็ว)

- เปิดแอป เชื่อมต่อ Robo X

- ใช้โหมด "Create Action"

- เปิด Mode Off ขยับด้วยมือ บันทึก Step

- Save Action

**วิธีที่ 3:** ใช้ PS2 + PC ร่วมกัน (ยืดหยุ่น)

- ใช้ PS2 ขยับแขนกลไปท่าที่ต้องการ

- บันทึก Step ใน PC

- ปรับแต่งเวลาและมุมใน PC

**3. สร้าง Action ตามแผน**

**ตัวอย่าง:** สร้าง Action "หยิบช้อน"

**ลำดับ Step:**

- Step 1: ท่าเริ่มต้น (ปลอดภัย)

- Step 2: หมุน Base ไปหาตำแหน่ง A (ช้อน)

- Step 3: ยก Shoulder + งอ Elbow เอื้อมลงไป

- Step 4: ปรับ Wrist ให้พร้อมจับ

- Step 5: เปิด Gripper (กาง)

- Step 6: ลดลงต่ำจนถึงช้อน

- Step 7: ปิด Gripper (จับ)

- Step 8: ยกขึ้น

เวลาแต่ละ Step: 500-1500 ms (ปรับตามความเร็วที่ต้องการ)

**4. การทำงานควบคู่ (Parallel Working)**

- โปรแกรมเมอร์: สร้าง Action บน PC/App

- วิศวกร: จัดสนาม ทำเครื่องหมายตำแหน่ง

- ผู้ทดสอบ: เตรียมเอกสารบันทึก เช็คลิสต์

- นักนำเสนอ: เริ่มเขียนสคริปต์นำเสนอ

**5. เคล็ดลับการสร้าง Action ที่ใช้ได้โดยไม่มีเซ็นเซอร์**

**DO (ควรทำ):**

- วางของตำแหน่งเดิมเสมอ

- ทำเครื่องหมายชัดเจน

- ทดสอบ Action หลายครั้ง ปรับจนแม่นยำ

- สร้าง Action สำรอง (ถ้าของเลื่อนนิดหน่อย)

- บันทึกค่ามุม Servo ไว้ (กรณีต้องแก้ไข)

** DON'T (ไม่ควรทำ):**

- พึ่งพา "แขนกลหาของเอง" → ต้องใช้ Camera

- คาดหวังว่า "แขนกลรู้ว่าของอยู่ไหน" → ต้องใช้ Sensor

- วางของสุ่มทุกครั้ง → Action จะใช้ไม่ได้

- ลืมทำเครื่องหมายตำแหน่ง → วางไม่ตรง

**ส่วนที่ 2: ทดสอบและแก้ไข (20 นาที)**

**กระบวนการทดสอบแบบเป็นระบบ**

**ขั้นที่ 1: ทดสอบ Action ทีละตัว (10 นาที)**

**วิธีทดสอบ:**

- **เตรียมสนามทดสอบ**

- วางอุปกรณ์ตามตำแหน่งที่ทำเครื่องหมายไว้

- ตรวจสอบว่า Robo X อยู่ในท่าเริ่มต้น

- **ทดสอบ Action แรก (เช่น "หยิบช้อน")** 
**รอบที่ 1 - เล่นช้าๆ Step by Step:**

- เล่น Step 1 → หยุด → สังเกต

- ถาม: "ถูกต้องไหม? แขนกลไปถึงตำแหน่งที่ต้องการหรือไม่?"

- เล่น Step 2 → หยุด → สังเกต

- ทำจนจบทุก Step

- บันทึกปัญหาที่เจอ

**รอบที่ 2 - เล่นเต็มรูปแบบ:**

- เล่น Action ทั้งหมดไม่หยุด

- สังเกต:

-  หยิบของได้ไหม?

-  ของตกไหม?

-  การเคลื่อนไหวลื่นไหลไหม?

-  ใช้เวลาเท่าที่คาดไว้ไหม?

**รอบที่ 3 - ทดสอบซ้ำ:**

- เล่นซ้ำอีก 2-3 ครั้ง

- เช็คว่าทำได้เหมือนเดิมทุกครั้งไหม (Consistency)

- สำคัญ: เพราะไม่มีเซ็นเซอร์ = ต้องแม่นยำทุกครั้ง

- **บันทึกผลการทดสอบ ใช้แบบฟอร์ม:**

| **TEST LOG (บันทึกการทดสอบ)** |
| --- |
| **Action: หยิบช้อน ** ผู้ทดสอบ: ______________________________________________________  ครั้งที่ 1: ☐ สำเร็จ ☐ ล้มเหลว  ปัญหา: _________________________________________________________  ครั้งที่ 2: ☐ สำเร็จ ☐ ล้มเหลว  ปัญหา: _________________________________________________________  ครั้งที่ 3: ☐ สำเร็จ ☐ ล้มเหลว  ปัญหา: _________________________________________________________  อัตราความสำเร็จ: __/3 สรุป: ☐ ผ่าน ☐ ต้องแก้ไข |

**ทดสอบ Action ถัดไป **

ทำซ้ำกับ Action ที่ 2, 3, 4 บันทึกทุก Action

**ขั้นที่ 2: ระบุและจัดลำดับปัญหา (5 นาที)**

**ปัญหาที่พบบ่อย (เมื่อไม่มีเซ็นเซอร์):**

| **ปัญหา** | **สาเหตุที่เป็นไปได้** | **วิธีแก้** |
| --- | --- | --- |
| จับไม่ถึงของ | ของวางไม่ตรงตำแหน่ง | ทำเครื่องหมายใหม่ให้ชัด |
|  | Action บันทึกผิดตำแหน่ง | แก้ไข Step ใน PC/App |
|  | Base หมุนไม่พอ/เกิน | ปรับมุม Servo 1 |
| จับแล้วของหลุด | Gripper หุบไม่แน่น | เพิ่มมุมปิด Gripper |
|  | เคลื่อนไหวเร็วเกิน | เพิ่มเวลาแต่ละ Step |
|  | ของลื่น | เปลี่ยนของที่หยิบ (ใช้ที่หยิบง่ายกว่า) |
| การเคลื่อนไหวกระตุก | เวลา Step น้อยเกิน | เพิ่มเวลาเป็น 1000-1500 ms |
|  | Step ห่างกันมาก | เพิ่ม Step กลางๆ |
| วางไม่ตรง | ตำแหน่งวางไม่ชัด | ทำกล่อง/พื้นที่รองรับใหญ่ขึ้น |
|  | Wrist หมุนผิด | ปรับมุม Servo 4, 5 |
| Action ครั้งที่ 2 ทำไม่ได้ | ของเลื่อนจากที่เดิม | กลับไปวางตำแหน่งเดิมด้วยมือ |
|  | แขนกลไม่กลับท่าเริ่มต้น | เพิ่ม Step สุดท้าย "กลับท่าเริ่มต้น" |

**ขั้นที่ 3: แก้ไขปัญหา (5 นาที)**

**กลยุทธ์การแก้ไข:**

**วิธีที่ 1:** แก้แบบเร็ว (Quick Fix) - ใช้เวลา 2-3 นาที

- ปรับตำแหน่งอุปกรณ์ให้ตรง (วางใหม่)

- เปลี่ยนของที่หยิบเป็นของที่หยิบง่ายกว่า

- เพิ่ม/ลดเวลา Step เล็กน้อย

- เหมาะกับ: ปัญหาเล็กน้อย

**วิธีที่ 2:** แก้แบบละเอียด (Deep Fix) - ใช้เวลา 5-10 นาที

- เปิด PC/App แก้ไข Step

- ปรับมุม Servo แต่ละตัว

- เพิ่ม/ลบ Step

- ทดสอบใหม่

- เหมาะกับ: ปัญหาใหญ่

**วิธีที่ 3:** ใช้แผนสำรอง (Plan B)

- ถ้าแก้ไม่ทัน → ใช้ PS2 ควบคุมด้วยมือแทน

- หรือลดขอบเขตโครงงาน (ทำน้อยลง)

- เหมาะกับ: เมื่อเหลือเวลาน้อย

**ขั้นที่ 4: ทดสอบซ้ำหลังแก้ไข (จนหมดเวลา)**

- ทดสอบ Action ที่แก้ไข

- ถ้าผ่าน → ไปแก้ Action ถัดไป

- ถ้าไม่ผ่าน → แก้ซ้ำ หรือใช้แผน B

**เป้าหมาย:**

- Action ทำงานได้ถูกต้องอย่างน้อย 70% (เช่น 6 Action มี 4-5 Action ที่ใช้ได้)

- สามารถสาธิตโครงงานได้ (ถึงแม้บางส่วนจะใช้ PS2 ควบคุมด้วยมือ)

### **ส่วนที่ 3: ฝึกซ้อมและปรับปรุง (10 นาที)**

**เป้าหมาย:** ฝึกให้โครงงานทำงานได้อย่างต่อเนื่องและราบรื่น

**ขั้นที่ 1: ฝึกรันโครงงานทั้งหมด (5 นาที)**

- **Reset สนาม**

- วางอุปกรณ์ทั้งหมดกลับตำแหน่งเริ่มต้น

- ตรวจสอบเครื่องหมายยังชัดเจนอยู่ไหม

- **เล่น Action ทั้งหมดตามลำดับ**

- Action 1 → Action 2 → Action 3 → ...

- **ไม่หยุด** ให้รันจนจบ

- จับเวลาว่าใช้เวลาเท่าไร

- **บันทึกปัญหาที่เจอขณะรันต่อเนื่อง**

- การเปลี่ยน Action อาจไม่ลื่นไหล

- ของที่วางไว้อาจไม่ตรงสำหรับ Action ถัดไป

- แขนกลอาจชนของที่วางไว้แล้ว

**ขั้นที่ 2: สร้าง "Action ทำความสะอาด" (2 นาที)**

**ปัญหาพบบ่อย:** หลังจากทำ Action 1 เสร็จ ตำแหน่งแขนกลไม่เหมาะสำหรับ Action 2

**วิธีแก้:**

- สร้าง Action เสริม: **"กลับท่าบ้าน" (Home Position)**

- Action นี้ทำหน้าที่: ย้ายแขนกลกลับท่าเริ่มต้นที่ปลอดภัย

- เรียกใช้หลังจบทุก Action

**ลำดับใหม่:**

Action 1: หยิบช้อน

   ↓

[กลับท่าบ้าน]

   ↓

Action 2: หยิบส้อม

   ↓

[กลับท่าบ้าน]

   ↓

Action 3: หยิบจาน

   ↓

[กลับท่าบ้าน] ✅ ทำให้รันต่อเนื่องได้ดี

**ขั้นที่ 3: ฝึกการนำเสนอ (3 นาที)**

**หน้าที่นักนำเสนอ:**

- **เตรียมสคริปต์สั้นๆ (30 วินาที - 1 นาที)**

  "สวัสดีครับ/ค่ะ

   ทีมเราคือทีม ________

   โครงงานของเรา ชื่อ ________

 **  เป้าหมาย: **[บอกว่าโครงงานทำอะไร]

**   วิธีควบคุม:** [บอกว่าใช้ PS2/App/PC อย่างไร]

**   จุดเด่น:** [บอกว่าโครงงานนี้ดียอดเยี่ยมตรงไหน]

   

   ขอเชิญชม!"

- **ฝึกพูดคล่อง**

- นักนำเสนอฝึกพูดดังๆ 2-3 ครั้ง

- สมาชิกในทีมให้ Feedback

- **ซ้อมเต็มรูปแบบ (Dry Run)**

- นักนำเสนอพูด + สาธิตโครงงานจริง

- จับเวลา (ไม่เกิน 3 นาที)

- ปรับปรุงถ้าจำเป็น

**สรุปคาบที่ 3:**

**แต่ละทีมควรมี:**

- Action ที่ทำงานได้อย่างน้อย 70%

- สนามที่จัดเรียบร้อย มีเครื่องหมายชัด

- เอกสารบันทึกปัญหาและวิธีแก้

- พร้อมสาธิตในชั่วโมงที่ 4

**คำแนะนำของครู:**

- "ไม่ต้องสมบูรณ์แบบ 100% - ที่สำคัญคือเรียนรู้และพัฒนา"

- "ถ้า Action บางตัวใช้ไม่ได้ ใช้ PS2 ควบคุมด้วยมือได้"

- "อธิบายให้ดี ว่าทำไมถึงเลือกออกแบบแบบนี้"
