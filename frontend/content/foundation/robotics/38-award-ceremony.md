Teacher Guide & Competition Management

**เตรียมการก่อนเริ่ม Championship**

- ตรวจสอบ Robo X ทุกเครื่อง — ชาร์จ, Bluetooth ใช้งานได้, ไม่มีสาย USB หัก

- ติดตั้ง PC Software ทุกเครื่อง + Test Connection

- ชาร์จ Joystick PS2 ทุกตัว — ทดสอบ Pair กับ Robo X

- ติดตั้ง Wonderbot บนแท็บเล็ตทุกเครื่อง + Test Bluetooth

- เตรียมบล็อก EVA 3 สี + ถาด + เทปกาวทำเครื่องหมาย A B C

- เตรียม Scoreboard (กระดาน/จอฉาย) สำหรับอัพเดทคะแนนทุกคาบ

**เทคนิคการบริหารคลาสการแข่งขัน**

- ใช้ไฟจราจร: 🟢 เริ่มแข่ง / 🟡 เตือนเวลา 2 นาที / 🔴 หยุด

- จดคะแนนทันทีหลังแต่ละด่าน ไม่รอสิ้นคาบ — ลดข้อโต้เถียง

- ถ้า Robo X เสีย ให้ทีมนั้นรอ — ไม่ให้คะแนนเยียวยา เพื่อความยุติธรรม

- บทบาทหมุนเวียน: ตรวจให้แน่ใจว่าทุกคนได้สัมผัสทุกระบบภายใน 10 คาบ

- ถ่ายรูป/คลิปสั้น ระหว่างแข่งขัน สำหรับ Highlight Reel คาบ 30

**สรุป Big Ideas — 3 ระบบ 3 จุดแข็ง**

**PC Software:** เหมาะกับงานที่ต้องการความแม่นยำสูง ทำซ้ำได้เป๊ะ รัน Offline ได้ไม่ต้องต่อสาย

   → ใช้เมื่อ: สร้าง Action Group ซับซ้อน, Combine หลายไฟล์, งานโรงงานที่ต้องทำซ้ำ

**Joystick:** เหมาะกับงาน Real-time ที่ต้องตอบสนองทันที ปรับเปลี่ยนได้ในทันที

   → ใช้เมื่อ: Sorting แบบ Ad-hoc, สถานการณ์ที่ไม่แน่นอน, ควบคุมจากระยะใกล้

**Wonderbot:** เหมาะกับงานที่ต้องการความยืดหยุ่น สร้างได้เร็ว ใช้งานผ่าน Bluetooth

   → ใช้เมื่อ: สร้าง/แก้ไข AG กลางสนาม, งานที่ต้องการ Loop, ควบคุมจากระยะไกล
