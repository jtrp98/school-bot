**แผนการเรียนรายวิชาวิทยาการคำนวณ/คอมพิวเตอร์**

**ระดับชั้น:** ประถมศึกษาตอนปลาย (ป.4-6)
**ระยะเวลา:** 4 คาบเรียน (คาบละ 50 นาที)
**วิชา:** วิทยาการคำนวณ/คอมพิวเตอร์
**หน่วยการเรียนรู้:** การควบคุม Robo X ผ่าน Application

**มาตรฐานการเรียนรู้และตัวชี้วัด**

มาตรฐาน ว 4.2: เข้าใจและใช้แนวคิดเชิงคำนวณในการแก้ปัญหาที่พบในชีวิตจริงอย่างเป็นขั้นตอนและเป็นระบบ ใช้เทคโนโลยีสารสนเทศและการสื่อสารในการเรียนรู้ การทำงาน และการแก้ปัญหาได้อย่างมีประสิทธิภาพ รู้เท่าทัน และมีจริยธรรม

**จุดประสงค์การเรียนรู้**

- เชื่อมต่อ Robo X เข้ากับ Application ผ่านระบบไร้สายได้ถูกต้อง

- อธิบายความแตกต่างระหว่างปุ่มกด (Button) และแถบเลื่อน (Slider) บนหน้าจอ App ได้

- ใช้หน้าจอ "Action Group" ใน App เพื่อจัดการท่าทางหุ่นยนต์ได้คล่องแคล่ว

- วิเคราะห์ข้อดี-ข้อเสีย ของการคุมผ่าน App เทียบกับ Joystick และ Program computer

- เชื่อมต่อ Robo X กับแอปได้อย่างถูกต้องและปลอดภัย

- ใช้โหมด Robot Remote Control เพื่อควบคุมข้อต่อและเรียก preset action ได้

- อธิบายหน้าที่ของ 3 โหมดในแอป ได้แก่ Robot remote control, Create actions, My actions ได้

- สร้าง action sequence อย่างง่ายในโหมด Create actions ได้

- บันทึก เรียกใช้ และปรับแก้ action ของตนเองใน My actions ได้

- วางแผนลำดับการเคลื่อนที่เพื่อให้ Robo X ทำภารกิจง่ายๆ ได้

- ใช้งานอุปกรณ์ด้วยความปลอดภัย มีวินัย และทำงานร่วมกับเพื่อนได้

**ส่วนที่ 1: การติดตั้ง Application**

**ชื่อแอป:** Wonderbot

> หมายเหตุสำหรับคุณครู: ชื่อแอปจริงของ Hiwonder ที่ใช้กับ Robo X คือ `Wonderbot` ให้ยึดชื่อนี้และชื่อเมนูภาษาอังกฤษในแอปจริงเป็นหลักเวลาสอนหรือสาธิตหน้าจอ

**ขั้นตอนการติดตั้ง:**

สำหรับ Android:

- เปิด Google Play Store/App Store

- ค้นหา "Wonderbot"

- กด Install

- รอดาวน์โหลดให้เสร็จ

สำหรับ iOS:

- เปิด App Store

- ค้นหา "Wonderbot"

- กด Get

- ยืนยันด้วย Face ID/Touch ID

**ส่วนที่ 2: การเชื่อมต่อ App กับ Robo X**

- เปิด Robo X

- กดปุ่มเปิด ไฟจะติด

- รอ 10 วินาที ให้เครื่องพร้อม

- เปิดแอป Wonderbot

- ดาวน์โหลด App จาก Playstore หรือ Appstore ค้าหา "Wonderbot" แล้วดาวน์โหลด

- กดไอคอนแอป

- เข้าสู่หน้าแรก

- เชื่อมต่ออุปกรณ์

- กดปุ่ม "" หรือ "เชื่อมต่อ"

- เลือก "Robo X" จากรายการ

- รอจนขึ้น "Connected"

- แตะเพื่อเลือกหุ่นยนต์ "Robo X"

- ทดสอบการเชื่อมต่อ

- กดปุ่ม Robot control ทดสอบ

- แขนกลควรขยับได้

**ส่วนที่ 3: ฟีเจอร์ในแอป**

แอปแบ่งเป็น 3 แท็บหลัก:

**แท็บที่ 1: Robot Control**

หน้าตา:

- มี Slider (แถบเลื่อน) สำหรับแต่ละ Servo

- มีปุ่ม Action Group ด้านล่าง

**การใช้งาน:**

**1. ควบคุม Servo แยกตัว:**

- Slider 1: Base (0-180°)

- Slider 2: Shoulder (0-180°)

- Slider 3: Elbow (0-180°)

- Slider 4: Wrist Rotation (0-180°)

- Slider 5: Wrist Pitch (0-180°)

- Slider 6: Gripper (เปิด-ปิด)

**วิธีใช้:**

- แตะที่ Slider แล้วเลื่อนซ้าย-ขวา

- ดูค่ามุมที่ต้องการ (แสดงเป็นตัวเลข)

- แขนกลจะขยับตามทันที

**2. เรียก Action Group:**

- ปุ่ม Action 1, 2, 3, 4...

- กดปุ่มใด Action นั้นจะทำงาน

- Action เหล่านี้มาจาก PC หรือสร้างในแอป

**ข้อดี:**

- ควบคุมแม่นยำ เห็นค่ามุมชัดเจน

- ปรับละเอียดได้ 1 องศา

- เรียก Action ได้สะดวก

**3. เรียก Reset:**

- เริ่มการทำงานของแขนกลใหม่

**4. การดึง Action จาก PC มาใช้งาน**

- สามารถเข้าไปที่ฟังก์ชั่น Add Action Group

- สามารถตั้งชื่อ Action ได้

- และต้องป้อนหมายเลขของ Action ให้ตรงกับ หมายเลขที่เราได้บันทึกไว้ใน PC

**แท็บที่ 2: Create Action**

**คืออะไร?**

- สร้าง Action ใหม่ด้วยการบันทึกการเคลื่อนไหว

**วิธีสร้าง Action:**

**ขั้นที่ 1:** เตรียม Action

- ตั้งชื่อ Action เช่น "หยิบบล็อก"

- กำหนดจำนวน Step (ขั้นตอน)

**ขั้นที่ 2:** เปิดโหมด Mode Off

- กดปุ่ม "Mode Off" หรือ "Teach Mode"

- Servo ทุกตัวจะหลวม สามารถขยับด้วยมือได้

- ข้อควรระวัง: แขนกลอาจตกลงมา ให้พยุงไว้!

**ขั้นที่ 3:** บันทึก Action

- ขยับแขนกลด้วยมือไปท่าที่ 1

- กดปุ่ม "Add Action" → บันทึกเป็น Step 1

- ขยับแขนกลไปท่าที่ 2

- กดปุ่ม "Add Action" อีกครั้ง → บันทึกเป็น Step 2

- ทำซ้ำจนครบทุก Step

**ขั้นที่ 4:** ตั้งค่าเวลา

- กำหนดเวลาแต่ละ Step (เช่น 1000 ms = 1 วินาที)

- ค่ามากขึ้น = เคลื่อนไหวช้า นิ่มนวล

- ค่าน้อยลง = เคลื่อนไหวเร็ว กระตุก

**ขั้นที่ 5:** ทดสอบ Action

- กดปุ่ม "Play" หรือ "▶"

- ดู Action ทำงานถูกต้องหรือไม่

- ถ้าไม่ถูกใจ → แก้ไข Step ที่ผิด

**ขั้นที่ 6:** บันทึก Action

- กดปุ่ม "Save Action"

- Action จะถูกเก็บไว้ในแอป

**ขั้นตอนการสร้างกลุ่มปฏิบัติการ:**

- คลิก **"ปิดมอเตอร์"** จากนั้นคลิก **"ตกลง"** เพื่อปิดเซอร์โว

- คลิกไอคอนถัดจาก " 1000ms " เพื่อยืนยันเวลาดำเนินการ (เป็นมิลลิวินาที) สำหรับการดำเนินการใหม่ ป้อนเวลาในหน้าต่างป๊อปอัพ จากนั้นคลิก " ตกลง "

- นักเรียนสามารถขยับแขนหุ่นยนต์ไปยังท่าทางใดก็ได้ตามต้องการ หลังจากกำหนดตำแหน่งแล้ว ให้คลิก " เพิ่มการกระทำ " ซอฟต์แวร์จะอ่านค่าตำแหน่งปัจจุบันของเซอร์โวแต่ละตัวและบันทึกเป็นการกระทำใหม่ การกระทำใหม่จะถูกเพิ่มลงในแถวสุดท้ายของรายการปัจจุบันโดยอัตโนมัติ

- (ตัวเลือกเสริม) หากนักเรียนต้องการแก้ไขการกระทำที่สร้างไว้ก่อนหน้านี้ในรายการ Action Group ให้กดค้างที่การกระทำในรายการ หน้าต่างป๊อปอัพตัวเลือกการแก้ไขจะปรากฏขึ้นโดยอัตโนมัติ ดังแสดงในภาพด้านล่าง:

**แท็บที่ 3: My Action**

**คืออะไร?**

- ห้องเก็บ Action ทั้งหมดที่สร้างไว้

**ฟีเจอร์:**

- ดูรายการ Action ทั้งหมด

- แก้ไข Action (Edit)

- ลบ Action (Delete)

- เรียก Action มาเล่น

- ส่งออก Action ไปยัง PC (Export)

**การจัดการ Action:**

- เปลี่ยนชื่อ Action ให้เข้าใจง่าย

- ลบ Action ที่ไม่ใช้แล้ว

- สำรอง Action ที่สำคัญ
