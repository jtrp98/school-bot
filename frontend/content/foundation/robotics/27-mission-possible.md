**คาบที่ 19 — Mission Possible ภารกิจ Action Group — หยิบและวางบล็อก (50 นาที)**

| **เป้าหมายคาบนี้** ออกแบบและสร้าง Action Group สำหรับภารกิจหยิบ-วางบล็อกสำเร็จอย่างน้อย 2/3 ด่าน ใช้ความรู้เรื่อง Index, Time, Servo ID ออกแบบ Action sequence อย่างเป็นระบบ ทดสอบ วิเคราะห์ข้อผิดพลาด และปรับปรุง Action Group ได้ เรียก Action Group จาก My Actions ผ่านหน้า Robot Control ได้ | **อุปกรณ์** Robo X (เปิดและรอ Bluetooth พร้อม) แท็บเล็ต/มือถือ — Wonderbot ใบงาน Action Designer (ใบงาน 17) บล็อก EVA 1 ชิ้น |
| --- | --- |

**สนาม:** วางเทปกาวบนโต๊ะ 3 จุด A B C

• A = จุดเริ่ม (บล็อกวางรอ)

• B = จุดกลาง (พักบล็อก)

• C = จุดปลาย (เป้าหมาย — ถ้วยเล็กกว้าง 6 ซม.)

• ระยะ A→B = 15 ซม. | B→C = 20 ซม.

**ตารางกิจกรรม**

| **เวลา** | **กิจกรรม** | **ครูทำ** | **นักเรียนทำ** |
| --- | --- | --- | --- |
| 0–5 นาที | Warm-up: ทบทวน "วิธีสร้าง Action Group" 5 ขั้นตอนอย่างรวดเร็ว | ถาม-ตอบเร็ว | ตอบจากความจำ |
| 5–15 นาที | บรีฟภารกิจ + วางแผน Action sequence | แจกใบงาน อธิบายด่าน | เขียน Plan ลงใบงาน Part 1 |
| 15–40 นาที | ปฏิบัติ: สร้าง Action Group + ทดสอบ 3 ด่าน | เดินดู บันทึกเวลา | สร้าง → Run → บันทึกผล |
| 40–47 นาที | Bonus: เรียก Action จาก Robot Control | สาธิตการ Add Action Group | เชื่อม My Actions → Robot Control |
| 47–50 นาที | รวมคะแนน + Debrief | ประกาศผล | แชร์เทคนิคพิเศษ |
