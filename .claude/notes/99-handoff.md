- อะไรที่เลื่อนไป ต้องบอกผู้ใช้ว่าทำเฟสไหน และลงตาราง "เลื่อนไปทำทีหลัง" ใน roadmap · ห้ามตัดทิ้งเงียบ ๆ
- ถามทีละคำถาม · ตอบภาษาไทย · ทำทีละส่วนแล้วเทียบภาพกับ mockup
- ห้าม commit, build installer หรือเปิดพอร์ต/ทดสอบบอร์ดจริงถ้าผู้ใช้ไม่สั่ง

## ตรวจงาน

- จาก `app/frontend`: `npm run typecheck` · `npm run test:i18n` · `node --test tests/block-lab-blocks.test.mjs tests/block-lab-boards.test.mjs` (`block-lab-blocks` ต้องมี `engines/mixly/bin/windows-amd64/mixly-engine.exe` · build ด้วย `scripts/build-engine.ps1 -Engine mixly -Test`)
- ดูหน้าจริง: `.claude/launch.json` → `frontend-preview` แล้วเปิด `/?preview=1&view=block-programming` ที่ 1440×900 (หน้าเชื่อมบอร์ด: เพิ่ม `&devices=many` แล้วกด "เปลี่ยน")
- build installer: เครื่องนี้ไม่มี Zig ให้ใส่ CMake ของ VS 2022 เข้า PATH ก่อน (`C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin`) แล้วรัน `scripts/package-desktop.ps1` · ถ้า dev server เปิดอยู่ ให้หยุดก่อน ไม่งั้น `npm ci` ลบ `node_modules` ไม่ได้
- Go: `.tools/go/bin/go.exe` (ตั้ง `GOCACHE`/`GOPATH` ไปที่ `.tools/gocache`, `.tools/gopath`, `GOTOOLCHAIN=local`) · engine mixly ต้อง `GOWORK=off`
